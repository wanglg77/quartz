# 《中医病历书写基本规范（第一版）》书籍概览

> [!info] 书籍定位
> 本书由参与卫生部和国家中医药管理局《中医病历书写基本规范》修订工作的项目组专家编写，旨在指导临床医师落实新规范要求，强化基本功训练。

## 一、 编写基本原则
1.  **突出重点**：注重《规范》内涵，强化中医特色。
2.  **四性统一**：着重病历的科学性、系统性、完整性、**法律性**。
3.  **实战导向**：规范医师行为，吸收全国示范中医医院的优秀病历案例。

## 二、 主要内容架构

| 章节 | 核心内容 |
| :--- | :--- |
| **一、通则** | 中医病历书写的基本要求与通用规则 |
| **二、基本规范** | 门急诊病历、住院病历的具体书写内容与要求 |
| **三、案例举例** | 各主要临床科室病历书写要点、各类知情同意书模板 |
| **四、考评标准** | 中医病历检查评价标准 |
| **五、附录** | 医疗机构病历管理规定、电子病历基本要求等 |
